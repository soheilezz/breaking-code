# Breaking Code

بازی کلمه‌ای دو تیمی با حال‌وهوای **Breaking Bad**. ساخته‌ی Soheil Ezzati ([@soheil_ezzati](https://instagram.com/soheil_ezzati))

## تغییرات این نسخه
- **کارت‌ها:** وقتی کارتی برمی‌گرده، پرتره‌ی پاپ‌آرت یکی از کاراکترهای Breaking Bad نشون داده می‌شه؛ همراه با شماره و اسم عمودی. رنگ کارت همچنان رنگ تیم رو نشون می‌ده (سرخ، آبی، رهگذر و قاتل).
- **۳۱ کاراکتر:** والتر، جسی، گاس، مایک، هنک، سال، اسکایلر، ماری، جونیور، هکتور، توکو، بجر، اسکینی پیت، هیوئل، گیل، جین، تاد، جک، لیدیا، تورتوگا، وندی، کریزی ۸، گومز، لئونل، براک، آندریا، تد، گرچن، تدی (خرس صورتی)، هایزنبرگ و آشپز (لباس ضدشیمیایی).
- **بدون تکرار:** هر کارت در یک دست کاراکتر مخصوص خودش رو داره و ترکیب کاراکترها در هر دست عوض می‌شه. کارت قاتل همیشه هایزنبرگ یا آشپزه.
- **آواتار بازیکن:** آپلود عکس حذف شد. هر کسی که وارد بازی می‌شه، یه چهره‌ی تصادفی از Breaking Bad می‌گیره و با زدن روی آواتار می‌تونه عوضش کنه.
- **ظاهر فانتزی‌تر:** کریستال‌های آبی شناور، خونه‌های جدول تناوبی در پس‌زمینه، دود رنگی، چرخیدن سه‌بعدی کارت موقع برگشتن، برق روی کارت و خونه‌ی عنصر روی پشت کارت‌ها.

## پوشه‌ها
- `release/BreakingCode.apk`: فایل نصبی اندروید
- `web/`: نسخه‌ی وب آماده‌ی اجرا. با GitHub Pages هم بالا میاد
- `src-skin/`: کد خوانای کاراکترها، کامپوننت‌ها و استایل‌های جدید

## نصب
نسخه‌ی قبلی رو اول پاک کنید، چون امضای APK فرق کرده. بعد `BreakingCode.apk` رو نصب کنید.
